## 需要其他模块完成的工作

### Core / 插件宿主

- T06a 已在 PluginBridge 处理存储 HostRequest，关联 request_id 并校验身份、权限、deadline、TTL 和容量；模型/任务当时仍需扩展（T06b/T06c 后续已实现并本机验收，详见台账）。
- T06a 已使用 RuntimeTransaction 原子提交存储写入、七天幂等响应和审计，同键不同内容 CONFLICT；未来扩展应保持相同原子性。
- T05a 已将公共 Runtime 改为 StorageResult，桥接业务实现需将 Unavailable/Conflict/Corrupt 映射到 UPSTREAM_UNAVAILABLE/CONFLICT/INTERNAL；不能对未检查的 variant 取业务结果。
- 核对 `ports.hpp` 在实际应用服务中的事务所有权、Scheduler 领取与 fencing、错误和关闭语义，并以契约测试验证；当时只是接口草案，尚无完整实现（T05a/T05b 后续已落地，详见台账）。
- T06a 已将 validate_host_request 接入存储入口，覆盖 UTC deadline、TTL、权限、限额、存储故障和幂等；模型/任务当时仍需补齐其各自验证，包括 IANA 时区与夏令时（T06b/T06c 后续已实现并本机验收，详见台账）。
- RuntimeTimePoint 已为 UTC 系统时钟；T05b 已验证重启恢复，仍需在业务服务接线后验证时钟跳变和调度策略。
